# Deployment restriction

This version supports local single-user development only; follow README.md. Do not deploy publicly: process-local data, no public authentication, no TTL, no multi-worker coordination.

Previous Render/Compose configurations are preserved under docs/legacy with .disabled suffixes. Historical URLs and reports do not verify present code or remote service state. Re-enabling deployment needs separate review and explicit approval. No remote service was changed in this audit.
