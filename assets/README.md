# Existing Infera icon

These assets reuse the Binary mark and blue/indigo tile from Infera's existing website header. The mark has not been redesigned.

- `infera-icon.svg`: repository README and source artwork.
- `infera-icon.png`: 512 px raster export of the same mark.
- `infera-social-preview.png`: 1280 × 640 GitHub preview, the unchanged mark centered on the existing dark background.

The same SVG is used for the header/footer, app icon, and HTML reports. Browser ICO and Apple PNG assets are raster exports of it. A backend regression test keeps the SVG copies identical.

The Binary paths originate from Lucide, distributed under the ISC license in [LUCIDE-LICENSE](LUCIDE-LICENSE). Infera is independently developed by Aritra Saha.
